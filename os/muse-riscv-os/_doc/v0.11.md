# muse-riscv-os v0.11（已實作，`test.sh` 42 項全過）

方向：shell 補完（glob、`exec envp`、引號重定向檔名）+ loader Permission 加固。on-disk 格式不動。

## 1. glob `*`/`?`（sh 純 user 層）

- `tokenize_env` 加 `lit` mask：single 引號/跳脫/`$`孤字為 literal；`$VAR` 展開在雙引號內為 literal、之外為可 glob。
- `expand_globs`：含未引用 `*`/`?` 的 token 才展開；以最後 `/` 切 dir/pattern（無 `/` 用 cwd）；`getdents` 列舉 + `fnmatch`（`*` 回溯、`?` 單字）；上限 8 argv（溢出丟棄）；零匹配保留字面（nullglob off）；`.` 開頭隱藏檔僅在 pattern 以 `.` 開頭才配（bash-like）。
- pipe 兩側、`&` 背景、`execve` 前皆走同一展開。

## 2. `exec envp`（`SYS_EXECVE=34`）

- `task::exec(pid, path, args, env)`；`push_args` 布局（低→高）：`[argc][argv+NULL][envc][envp+NULL][strings]`；entry：`a0=[sp]`、`a1=sp+8`、`a2=a1+8*(a0+1)+8`。
- `_start`（11 個 app 同一樣板）：算出 envp 陣列位址 + `envc`，存入 user-lib `ENVIRON_P/C`（`#[no_mangle] #[used]`——前者解 asm 符號名，後者防 `--gc-sections` 誤刪）。
- 舊 `SYS_EXEC` 走同一布局、envc=0（統一布局，不分叉）。
- `user-lib`：`execve()`、`env_count()`、`env_str(i)`；`printenv` 新工具（全印/`printenv KEY` 過濾）。
- sh 三條 spawn 路徑（前景/pipe/`&`）一律 `execve` + `mkenvp` 攤平；usertests 等直調 `exec`（空 env）不變。

## 3. 引號重定向檔名 + `$VAR` 檔名

- `>`/`>>`/`<`/`2>` 的檔名：引號開頭則取到配對引號，否則到下個空白；再經 `expand_str` 做 `$VAR` 展開（`echo data > $RF`、`cat "$RF"` 可用）。

## 4. loader：BSS 權限加固（`pt::protect`，本版真 bug）

- 根因：零 filesz 的 BSS 段（或 BSS 尾）若與 RX text/rodata 同頁，`map_one`/`alloc_map_user` 的 first-mapper-wins 使其維持不可寫；user `_start` 首條 `sd .bss` 即 store fault（cause=15，`sepc=_start+0x16`，`stval=ENVIRON_P`，JTAG 級定位）。
- 修法：每段 map 完對 `[vaddr, vaddr+memsz)` 做 `protect OR R/W/X`（後段覆蓋前段，符合連結順序；絕不加 U 以外位）。
- v0.10 未爆：舊 app 入口不寫 `.bss`（讀零可，寫才 fault）。

## 5. 布局鐵律（血的教訓）

- `push_args` 布局與 11 個 `_start` 是鎖定對（lockstep）：`a1=sp+8=argv`、`a2=envp`。有版曾把 envp 放 argc 與 argv 之間，argv 全錯位；另有版 `p & !15` 在寫完後掩膜使 sp 滑到 argc 槽下（v0.7 #1 同類）。現行：先算 `need`、對齊 sp、再寫，附 `debug_assert!(sp & 15 == 0)`。
- 判據：`riscv64-unknown-elf-objdump -d` 核對 `_start` + `nm` 核對 `ENVIRON_*` 位址。

## 6. 驗收（autorun + `test.sh` 3 斷言）

- `run_capture` 既有管線拿來測 parser：`echo /WD/*` 含 `/F` 且 `echo "/WD/*"` 字面 ⇒ `glob PASS`；`export FPE` + `printenv FPE` 含 `FPE=hello-envp\n` ⇒ `envp PASS`；`echo data > $RF` + `cat "$RF"` 前綴 `data\n` ⇒ `redirenv PASS`（echo 會把自家 PASS 行也寫進檔，只斷言前綴）。
- `test.sh` 加 3 個 `check`（run1）。

## 7. 非目標

- `[...]` 字元類、`**` 遞迴、`nullglob` 選項、glob 跨目錄 `/a/*/b`（只切最後 `/`，中段 `*` 視為字面的一部分比對——實際上 dir 含 `*` 會 `walk` 失敗 → 保留字面，行為確定）。
- `MAP_FIXED`/檔案映射（v0.8 已排除）；`env` 跨 `exec` 以外的傳遞（`export` 仍 shell-local）。
