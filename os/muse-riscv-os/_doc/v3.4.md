# muse-riscv-os v3.4（主線：信任鏈——完整性 + 認證）

## 0. 動機

包越裝越多，來源必須可驗。本版兩層，各自獨立：
完整性（sha256，下載驗）+ 私仓認證（token）。

範圍誠實聲明：完整性 hash 擋的是傳輸損壞/調包，不是不對稱簽名
（ed25519 要先有 SHA-512，~500 行 crypto——進 v3.6+ 候選池，
不expanding scope 在這裡）。user-net 只信本地的模型下，
完整性 + 認證就是可交付的信任鏈。

## 1. 語義

```
ctr login <token>                     # 寫 /pkg/token，下次 fetch 自動帶上
```

- sha256（guest `user-lib` 新增，core-only，host-tests 先行
  NIST 向量）：manifest 加 `sha256: <64hex小寫>` 行 = 按 manifest
  順序串起的所有 layer bytes 的 hash。guest 下載完**先驗後解**：
  缺行 → `ctr: sha256 missing`；不對 → `ctr: sha256 mismatch`
 （+ install 回滾 / upgrade 中止，沿用既有 loud 紀律）。
  user-lib 為此加 `#[cfg(test)]`（`cfg_attr(not(test), no_std)` +
  test 版 ecall stub；riscv 構建零影響）+ `cargo test -p user-lib`
  進 test.sh 快門。
- wget：第 5 個 argv（可選）= token 原文，發
  `Authorization: Bearer <token>` 頭。`run_wget` 包一層
  `run_wget_auth(..., Option)`，pull 舊路徑不動。
- `ctr login`：token 字符集 `[A-Za-z0-9-_]` ≤63（防 CRLF 注入；
  wget 側信任已驗 token）。寫 `/pkg/token` → `login ok`。
  install/upgrade/index 全經 token（有檔就帶；公開路由忽略頭）。
- registry：僅 `secret` 系路由要頭（`bearer test-token`，
  大小寫不敏感比）：缺/錯 → 401。新包 `secret`（echo 作
  `bin/secret` + `secret.txt`，版本化 + index 照舊）與 selectively
  壞包 `tampered`（manifest 記原 hash，tar 翻一個 bit——
  mismatch 負向實證）。
- pkgbuild：打包自動算 sha256 寫 manifest（fortune 路由跟著對，
  零手動）。
- 非目標：ed25519/非對稱簽名、key 輪換、吊銷/過期、TLS、
  token 加密存儲（明文躺 `/pkg/token`，寫死在這）。

## 2. suite（確定性設計：先拒後納 + 篡改）

db 乾淨時（autoremove 段後）：

```
ctr install 10.0.2.2 8091 secret   → pkg fetch failed (index) [401 無 token；
無約束安裝先抓 index，這一行即證明]
ctr login test-token                → login ok
ctr install 10.0.2.2 8091 secret   → pkg-installed secret 1.0
secret secret-marker                → secret-marker
ctr remove secret                   → pkg-removed secret
ctr install 10.0.2.2 8091 tampered → ctr: sha256 mismatch
```

- test.sh +6 項（run1）：`pkg fetch failed (index)`（此前綠 log
  從未出現——唯一來源就是這裡）、`login ok、
  `pkg-installed secret 1.0`、`secret-marker`、`pkg-removed secret`、
  `sha256 mismatch`。
- 手動：錯 token（401 同）、sha256 大小寫（registry 只發小寫；
  guest 只認小寫，寫死）、`login` 髒字符拒絕。
