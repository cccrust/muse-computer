# muse-riscv-os v0.5（已實作，`test.sh` 29 項全過）

延續 v0.4：中斷 I/O 已穩，主線轉向「更像 Unix 的路徑與 fd 語意」。核心、排程、測試框架小幅擴充；**on-disk 格式不動**（v0.2/v0.3 映像檔可直接用）。

## 1. `chdir` / `getcwd` 真實作（A2，核心）

現況 `SYS_CHDIR=16` 是 stub（直接回 0），`sh` 無法換目錄。

- `Proc` 加 `cwd: [u8;128] + cwd_len`（`/` 初始，`fork` 繼承，`exec` 保留）。
- 新增 `task::resolve_path(cwd, input) -> String`：相對路徑拼 `cwd`，正規化 `.`/`..`/`//`/尾 `/`（根保持 `/`）；檔名長度仍由 `disk::walk`（28B）把關。
- `sys_open/mkdir/unlink/link/getdents/exec` 一律先 resolve 再進 `fs::`。
- `SYS_CHDIR` 改真實作：resolve 後 `exists` 且 `stat kind==2`（dir）才設 cwd，否則 -1。
- 新增 `SYS_GETCWD=25`：`(buf, len)`，拷 cwd（含 NUL），回傳所需長度；`len==0` 或不足回 -1。
- `user-lib`：`chdir(path)`、`getcwd(buf, len)`。
- `sh`：內建 `cd <dir>`、`pwd`；`resolve()` 找 `/bin/<prog>` 不變，但使用者輸入的絕對/相對路徑（`cat f`、`./a.out`）直接試原 token。

## 2. `lseek` + `O_APPEND`（A3，核心）

現況 fd offset 只能順序推進，`>>` 做不了。

- 新增 `SYS_LSEEK=26`：`(fd, off: isize, whence)`，僅 file fd（kind==4）；`SEEK_SET=0/SEEK_CUR=1/SEEK_END=2`（END 用 `file_len`/`stat size`）；結果 `<0` 回 -1，否則設 `fd_off` 並回新 offset。pipe/stdin/stdout 回 -1。
- `open` 加 `O_APPEND=0x400`：存在檔則 `fd_off = len`；`O_TRUNC|O_APPEND` 並存時 TRUNC 先清再 append（= 空檔尾）。
- `user-lib`：`lseek(fd, off, whence)`，`O_APPEND` 常數文件註明。
- `sh`：解析 `>>`（append 寫，`O_CREATE|O_APPEND`，不截斷）；既有 `>` 語意不變。

## 3. `dup2` + `O_CLOEXEC` 收尾（A5，核心）

現況只有 `dup`（取最小空閒 fd），`2>&1`、指定 fd 重定向做不了。

- 新增 `SYS_DUP2=27`：`(old, new)`，0–15 範圍檢查；`old==new`（且已開）直接回 new；否則關 `new` 後複製 `kind/off/path`，回 new。
- `open` 加 `O_CLOEXEC=0x80000`：`Proc` 加 `fd_cloexec: [bool;16]`，`fork` 繼承旗標，`exec` 關掉有旗標的 fd（0/1/2 若被標也關——呼叫方負責）。
- `sh`：`exec_cmd` 的 `>`/`<` 改走 `open + dup2(target) + close`（不再依賴 close+dup 最小分配競態）；pipe 子行程同理。

## 4. `waitpid`（A1，順手）

現況 `SYS_WAIT` 只能等任一子行程，`jobs` 無法精準回收。

- 新增 `SYS_WAITPID=28`：`(pid: isize, status_ptr, options)`；`pid>0` 等指定，`pid==-1/0` 等任一；`WNOHANG=1` 無僵屍時回 0（不阻塞），阻塞版沿用既有 `-2` + yield 重試協議。
- `task::wait` 重構成 `waitpid` 內核，原 `wait` = `waitpid(-1)`。
- `user-lib`：`waitpid(pid, &mut code, options)`；`sh` `wait_foreground` 改 `waitpid(target)`，`drain_jobs`/`reap_poll` 保持 `wait` 語意。

## 5. `fsstat`/`df` + fsck 檢查（A6，順手）

- 新增 `SYS_FSSTAT=29`：`(buf, len)`，寫 ASCII `total=%u free=%u\n`（disk：掃 bitmap；ramfs fallback：固定回報）；回傳位元組數。
- `disk::count_free()`：掃 bitmap 計 0-bit（4MB 盤=8192 塊，開機後呼叫一次可接受；`df` 按需呼叫）。
- `user-lib`：`fsstat(buf, len)`；`sh` 內建 `df`。
- fsck 维持 v0.3 dirty-rebuild，不加新修復邏輯（只把 `count_free` 與 `df` 對齊，避免兩套算法打架）。

## 6. 驗收（`test.sh` 只加 run1 斷言，不動 run2/run3）

`sh` autorun 追加（順序在既有 `kill PASS` 之後、`setfg(prompt)` 之前）：

1. `mkdir /WD; chdir /WQ` 經 shell 序列：`echo hi > /WD/F` → `cd /WD` → `cat F` 比對 → `pwd` 印 `/WD` → 印 `[TEST] chdir PASS`
2. `echo b >> /WD/F`（append）→ `cat F` 兩行 → 印 `[TEST] append PASS`
3. `lseek` 自測（`*` 見下）：讀回第一位元組 + END 定位 → 印 `[TEST] lseek PASS`
4. `dup2` 自測：`dup2(fd, 7)` 後經 fd=7 讀回 → 印 `[TEST] dup2 PASS`
5. `waitpid` 自測：fork 速退子行程，`waitpid(child)` 精準回收且 code 正確 → 印 `[TEST] waitpid PASS`
6. `df` 自測：`fsstat` 回 `total=` 且 free < total → 印 `[TEST] df PASS`

`*` 為省一個新 crate，3–6 併入 `usertests`（已有 argv/讀寫 harness），或 sh 內聯小序列；`test.sh` 加 6 個 `check`。

## 7. 非目標

- COW fork、mmap、uid/權限、journal、網路、多 hart、indirect2。
- 完整 job control（`fg`）、shell 引號/`$VAR`/glob（留待 shell 體驗版）。
- `walk` 支援 `.`/`..` 輸入（resolve 層已正規化，disk 層不收 `..`）。

## 8. 動工順序

1. `task`: cwd 欄位 + resolve + fork/exec 繼承語意（host 可 `cargo test -p kernel` 先驗 resolve 純函式）。
2. `syscall`: chdir/getcwd/lseek/dup2/waitpid/fsstat + open flags + 全路徑 resolve。
3. `disk`: `count_free`；`user-lib` 包裝；`sh`: `cd/pwd/df` + `>>` + dup2 化重定向。
4. `usertests`/autorun 覆蓋 + `test.sh` 6 斷言；全量 `./test.sh`（host + 3 次 QEMU）。
