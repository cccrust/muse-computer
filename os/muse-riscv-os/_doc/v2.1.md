# muse-riscv-os v2.1（主線：PID namespace，容器第二層）

## 0. 動機

v2.0 把每個容器關進了自己的 root，但 `ps` 一看全機行程一覽無遺，
`kill 5` 能殺到別人家的小孩。本版給每個容器自己的 pid 視圖：
namespace 內 pid 從 1 開始，`getpid/ps/kill` 只認得自家人。
先不碰配額與網路（v2.2+）。

## 1. 設計（`task/mod.rs` 內，無新鎖）

### 1.1 數據：NS 表進 Sched（不另開鎖，省掉鎖序審計）

- `Ns { parent: usize, next: usize }`，`Sched.ns: Vec<Ns>`，ns 0 預建
  （root/init 名字空間）。
- `Proc += { ns: usize, lpid: usize, pending_ns: bool }`。
- root ns 特例：`lpid == global pid`（恆等，舊行為逐位元保留）。
  非 root ns：`lpid = ns.next++`，從 1 開始。

### 1.2 分配（fork 點）

- `finish_spawn`（init，parent 0）：`ns=0, lpid=pid`。
- `fork`：父 `pending_ns` 置位 → 建新 ns（`parent=父ns`），子 `ns=新、
  lpid=1`，清父 flag（**one-shot 語意**，與 Linux 常駐不同——可預測、
  可測；寫死在這）；否則子繼承父 ns，`lpid` 按上分配。
- `fork()` 回傳值、`waitpid` 回傳值：**一律 global pid**（內部身份；
  現有 `w == pid` 斷言零改動）。lpid 只從 `getpid`/`ps` 漏出去。
- `CloneInfo` 元組加兩欄（ns、pending 讀取；flag 清除走既有
  `get_mut(parent)` 段）。

### 1.3 名字空間視圖（只認自家人，root ns 因恆等而無感）

- `getpid()` → `lpid`（`SYS_GETPID` 改一行；root ns 不變）。
- `ps_snapshot(caller)` → 只列同 ns，印 lpid（root ns 輸出逐字同舊；
  既有 `ps` 測試找 `"1 "` 行——ns0 下 init 仍在 ✓）。
- `kill(target)` → 先配 `ns==caller.ns && lpid==target`，
  再退回 global pid（root ns 兩路徑同解；跨 ns 誤殺靠第一路擋掉）。
- `waitpid(target)`：children 表本來就是 global pid，target 比對加一路
  `lpid-in-waiter-ns`；回傳 global（上條理由）。`wait(-1)` 語意不動。
- `exit` reparent：孤兒跟著原 ns 走（init 按 global children 表照收，
  無 ns 檢查——收割路徑與名字空間正交）。

### 1.4 `SYS_UNSHARE = 46`（Linux 語意子集：只認新 pid ns）

- 對當前進程置 `pending_ns`（影響的是**下一個 fork 出來的孩子**，
  不是自己——Linux `unshare(CLONE_NEWPID)` 同語意）。
- 参数：無（`unshare()`）；其他 flags 回 `-1` 留坑（本版只做 pid）。
- `user-lib::unshare()`；sh builtin 兩個：`chroot <dir>`（chroot+chdir `/`，
  失敗報錯）、`unshare`（調用 + 印一行）。交互可用性一次到位。

## 2. `user/nstest`（自測，確定性優先）

- 父 `unshare()`→`fork()` 四次（每次重設 flag，各自新 ns）：
  子斷言 `getpid()==1`、空轉 `yield` 若干輪、`exit(40+i)`；
  其中一個子再 fork 孫（繼承同 ns，斷言 `getpid()==2`）。
- 父 `waitpid` 全收、校驗 code → `[TEST] ns PASS/FAIL`。
  （父看子一律 global pid；lpid 只在子內斷言——跨 ns 取值比較是坑，不測。）
- sh autorun `run_one` 跑它；test.sh +1 項（61+1=**62 項**）。

## 3. 驗收

- `./test.sh` 全綠（62 項），零 `PANIC`/`FAIL`，連跑 2 輪。
- `ns PASS` 穩定；手動 `chroot /ctr/demo` + `unshare` + `ps` 只見自家人。
- 舊測項零退化（重點：root ns 下 getpid/ps/kill/waitpid 逐位元同舊；
  `fork` 回傳仍是 global）。

## 4. 非目標（→ v2.2+）

- 多層嵌套 pid 映射（只記 parent 備查，不做祖先可見；夠用到 v2.x 末）。
- 空 ns 回收（僵屍 ns 留著，16 個 pid 上限都碰不到——真要做也是掃描）。
- cgroup-lite（frame 記賬+cap，v2.2）、netns/veth、overlayfs、
  capabilities/users、`pivot_root`。
