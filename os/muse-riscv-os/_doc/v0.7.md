# muse-riscv-os v0.7（已實作，`test.sh` 35 項全過）

方向：純 user 層（`user/sh`），不動 kernel syscall、不動 on-disk 格式。

## 1. 引號 + `$VAR` + `\` 跳脫（核心）

現況 `tokenize` 只切空白，`echo 'a  b'`、`echo "x>y"` 會被 pipe/重定向解析拆壞。

- `tokenize_env`：狀態機（normal/single/double）；single 內全字面；double 內 `$` 展開、`\` 跳脫；normal 另加空白斷詞。未閉合引號：吃到行尾（document，不報錯）。
- `$NAME`（`[A-Za-z0-9_]+`，`$` 後無名則字面 `$`）；未定義變數展開為空。
- pipe `|`、重定向 `>`/`>>`/`<`、背景 `&` 的掃描全部改走 `find_unquoted`（引號/跳脫感知）。重定向檔名不支援引號含空白（document：只有 argv 支援引號）。

## 2. 環境變數（shell-local）

- `Env`：16 組，name ≤31B、val ≤63B，`main` 棧上、`exec_cmd` 等函式傳參（刻意不用全域）。
- 內建：`export NAME=val`、`unset NAME`、`env`（列出）。展開點：fork 前的 parent 側（child 原樣）。
- 刻意不做 `exec envp`（要動 loader + 10 個 app 的 entry + argv 拷貝順序，留待後續版本）；跨 `exec` 傳遞不支援，文件註明。

## 3. 行編輯 + 歷史（16 條）

現況 prompt 用 `read_line`：無 echo（盲打）、無退格、無歷史。

- `read_edit`（sh 內 raw byte loop）：可見字元 echo、BS/DEL 擦除（`\b \b`）、`ESC[A/B` 上下歷史（附 draft 暫存 + `\rsh$ ...\x1b[K` 重繪）、`\r`/`\n` 結束並入歷史（非空才記）。
- ESC 殘缺序列（pipe EOF 情境）：有限重試後放棄，不卡死。
- `r<=0`：空行回 0（呼叫方 yield，與舊語意同）；有字則保留續等，不丟已打的字。
- Ctrl-C/Ctrl-D 語意不變（kernel 側：prompt fg=self，Ctrl-C 照殺；Ctrl-D 走 EOF）。

## 4. `fg` + `jobs` 顯示 pid

- `jobs` 改列 `pid`（既有只印 `jobs: none`）。
- 內建 `fg [pid]`：無參取最新；`setfg` 前後包 `wait_foreground`（與前景等待一致）。
- `exec_bg` 改回傳 child pid（呼叫方忽略即可）。

## 5. 驗收（autorun + `test.sh` 4 斷言）

- `run_capture`（sh 內）：pipe + fork + 子行程 `dup2(w,1)` 後跑 `exec_cmd`，parent 非阻塞排空 + `waitpid`，回傳位元組。輸出 <1KB 保證無死結。
- `echo 'a  b'` → `a  b\n` ⇒ `quote PASS`
- `export F=/WD/QQ` + `echo pre-$F-post` → `pre-/WD/QQ-post\n` ⇒ `env PASS`
- `echo hi &` + `fg` → jobs 空 ⇒ `fg PASS`
- history buffer 單元操作（push/get_rel）⇒ `history PASS`
- `test.sh` 加 4 個 `check`（run1）。

## 6. 非目標

- `exec envp`、glob `*`、`$()`/反引號、上下鍵以外的游標移動、`fc`。
- 重定向檔名引號、`>>` 與 `2>` 組合在引號內的邊界 case。

## 7. 實作結算：`push_args` 對齊 bug（v0.3 遺留）

- 現象：`echo pre-$F-post`（argv[1] 15B）等測試 FAIL，`echo` 印無參數預設句；tokenizer 經 stderr dump 證明正確，kernel `sys_exec` 拷貝的 `args` 也正確（argc=2、長度對），但 user 側 `_argc<=1`。
- 根因：`task::push_args` 尾部 `p & !15` 在字串總位元組 `total mod 16 < 8` 時把 `sp` 舍入到 argc 槽下方 8B，entry `ld a0,0(sp)` 讀到零頁的 0 → `argc=0`。v0.5 的 argv（`hello-arg` 9B、`/TESTDATA` 9B 等）恰好都落在安全區間，從未觸發。
- 修法：先墊 8B 使 `argv_base-8` 天然 16 對齊（見 `push_args` 註解），回傳值不再二次掩膜；附 `debug_assert!(sp & 15 == 0)`。
- 教訓：argv 長度邊界（10/11B）是現成的核心回歸測試——`env PASS` 即覆蓋 l1=15。
