# muse-riscv-os v3.11（主線：私包 + 刪包 API + logout）

## 0. 動機

v3.4 的認證只有一半：registry 認得 token，但包沒有公私之分
（除寫死的 secret），上架的東西也刪不掉。本版補齊管理面：
`--private` 上架、`logout`、 registry 刪包 API。

## 1. 語義

```
ctr login <token>    # 已有（v3.4）
ctr logout           # 新增：刪 /pkg/token → `logout ok`；無 token → `ctr: not logged in` exit 1
```

- 上架：`pkgbuild --private` → manifest PUT 帶 `X-Private: 1` 頭；
  registry 落 `.private` 標記檔於版本目錄。標記只認 manifest PUT
  （tar PUT 不看，順序無所謂——pkgbuild 先送 manifest）。
- 讀取門：`/pkg/<name>/<ver>/*`（manifest、tar、index 全體）
  若對應磁碟目錄有 `.private` 標記 → 無/錯 bearer 即 401。
  內建 secret 走舊硬編碼（不動它）。公開路由完全無感。
- 刪包：`DELETE /pkg/<name>/<ver>/`（尾斜線可有可無）+
  admin token → 刪磁碟目錄 + 撤路由 + 重生成 index →
  200 `deleted <name> <ver>`。錯 token → 401；不存在 → 404。
  guest 不調它（host 管理面；guest 的 `remove` 管的是已安裝）。
- `ctr install` 等 fetch 流程零改動（token 照帶，401 照爆，
  現有語義直接吃下私包）。
- 非目標：`--private` 已發布包的事後切換（重傳一次即是）、
  多 token/多用戶、配額、包版本列表 UI。

## 2. suite（確定性設計：先拒後納 + host 刪）

test.sh 在 v3.7 publish 步後加一行（同一 server，registry 活著）：

```bash
python3 tools/pkgbuild.py --crate tools/pkgdemo --pkg privdemo \
  --version 1.0 --bin fortune --private \
  --registry http://127.0.0.1:8091 --token admin-token || PASS=0
```

（包名/二進制名脫鉤沿用 pubdemo 前例；`/bin/fortune` 當時空著。）
autorun（v3.10 段後，db 乾淨；token 在——v3.4 登過，suite 照用）：

```
ctr logout                              → logout ok（刪 token）
ctr install 10.0.2.2 8091 privdemo     → 401（marker 沿用 fetch failed (index)，不新增）
ctr login test-token                    → login ok（舊 marker）
ctr install 10.0.2.2 8091 privdemo     → pkg-installed privdemo 1.0
ctr list                                  （PKGLS 行出現，不斷言）
fortune hello-from-priv                 → fortune-sez hello-from-priv
ctr remove privdemo                     → pkg-removed privdemo
```

host 側（§6 斷言區、殺 stub 前——guest 已用完 privdemo）：

```bash
# v3.11: registry delete API（host 側；guest 不調）
OUT=$(curl -s -X DELETE -H "Authorization: Bearer admin-token" http://127.0.0.1:8091/pkg/privdemo/1.0/)
echo "$OUT" | grep -q "deleted privdemo 1.0" || PASS=0
CODE=$(curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8091/pkg/privdemo/1.0/manifest)
[ "$CODE" = "404" ] || PASS=0
```

- test.sh +4 項（run1）：`logout ok`、`pkg-installed privdemo 1.0`、
  `fortune-sez hello-from-priv`、`pkg-removed privdemo`
  （401 沿用舊 marker；DELETE 走 host 斷言非 check）。
- 手動：錯 token DELETE（401）、刪不存在（404）、重傳覆蓋私包、
  `--private` 漏加頭（公開上架，不擋）。
