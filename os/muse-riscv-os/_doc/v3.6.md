# muse-riscv-os v3.6（主線：容器小件收尾——ps 限額 / rm -f / restart）

## 0. 動機

v2.x 留的三個容器小件，一次收完（都是只讀/組裝既有原語，
無新隔離層）：

1. `ps` 看限額（v2.8 欠賬：當時無 getter，只能印請求值）。
2. `rm -f`（跑中刪除：stop+rm 一鍵，docker 同款）。
3. `restart`（停了能起、跑了重起：跑參必須落盤，否則無從得知）。

## 1. 語義

```
ctr rm -f <name>
ctr restart <name>
```

- 新 syscall `SYS_CGSTAT=57`：`cgstat(id, out[3])` 讀
  `[limit_frames, cpu_pct, weight]`（解碼後：未設限 cpu=100、
  未加權 weight=1——與 v2.8 `detached` 行口徑一致；group 0
  照此默認）。id 越界 → -1。user-lib 包 `cgstat()`。
- `ps`：`CTRPS` 行尾追加 `mem=<f> cpu=<p> weight=<w>`
  （Up 與 Exited 兩路都加；既有子串斷言不受影響——只增不改）。
  活著的查 live cg，Exited 的查 state cg（group 元數據還在）。
- `rm -f`：state 不存在 → 沿用 `no such container`；活著 →
  走 stop 同款 kill+poll（抽共用 helper，不改 stop 行為），
  然後走 rm 全套。marker 沿用兩行（`stopped …` + `removed …`），
  無新 marker——舊測項即證明。
- `restart`：`run -d` 成功時多寫 sidecar `/ctr/<name>/.run`
  （內容 = `run` 之後的完整 argv 行，空格連接；寫失敗視同
  state 失敗：kill + exit 1）。`restart` 流程：
  無 `.pid` → `no such container`；無 `.run` → `ctr: no run spec`；
  活著 → 先 stop（同款）；fork + exec `/bin/ctr run <sidecar>`
  （嵌套 run -d 自己寫新 state + 印 `detached`），parent 轉 exit
  code；成功再印 `restarted <name>`。
  sidecar 空格 join/split（prog 參數含空格會壞——suite 不用，
  寫死在這，比發明轉義格式便宜）。

## 2. suite（確定性設計：配額行 + 強刪 + 重起）

```
ctr ftest                                      → ready（第二個生命週期名）
ctr run -d --memory 100000 --cpu 50 --weight 8 ftest /bin/linger 30
ctr ps                                         → CTRPS ftest.*mem=100000（regex 斷言 ps 行）
ctr rm -f ftest                                → stopped ftest (killed 2) + removed ftest
ctr rtest                                      → ready
ctr run -d rtest /bin/linger 30
ctr restart rtest                              → detached <new> … + restarted rtest
ctr stop rtest                                 → stopped rtest
ctr rm rtest                                   → removed rtest
```

- test.sh +6 項（run1）：`CTRPS ftest.*mem=100000`（basic regex，
  `check` 原樣透傳 grep）、`stopped ftest (killed 2)`、
  `removed ftest`、`restarted rtest`、`stopped rtest`、
  `removed rtest`。
- 手動：`restart` 已停容器（直接起）、`rm -f` 不存在（no such）、
  `restart` 無 sidecar（刪 `.run` 手動造）。

## 3. 非目標（→ v3.7+ 候選池）

sidecar 轉義、前台 run 的 restart（只有 -d 寫 sidecar）、
`restart` 保留舊 pid（pid 本來就不重複）、exec 帶 volume（v3.5 缺口）。
