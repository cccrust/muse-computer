# muse-riscv-os v0.9（已實作，`test.sh` 38 項全過）

方向：`ps` + `strace`-lite。on-disk 格式不動；純加法（2 syscall）。

## 1. `SYS_PS=32`

- `(buf, len)`：每行 `pid ppid state brk cwd\n`（state 字母：R=Runnable/Running、B=Blocked、Z=Zombie；brk 十進位；cwd 原樣），寫滿則截斷到行邊界（不斷行），回傳位元組；`len==0` 回 -1。
- 鎖策略：一次 collect（`sched` lock 內組字串，短臨界；行數 <32，512B 夠）。
- `user-lib`：`ps(buf, len)`；`sh` 內建 `ps`（印出）。

## 2. `SYS_TRACE=33`

- `(pid, on)`：設 `Proc.traced`（不判權限，本 OS 無 uid；`fork` 繼承 false，避免爆炸）。
- 被 trace 的行程每次 ecall 回傳後印一行：`[STRACE] pid=N id=A a0=X ret=R`（十進位；trap 內 `println!`，與既有 trap 印字同路徑）。
- 用量紀律：autorun 只開毫秒級（開→2~3 syscall→關），log 量可控。

## 3. 驗收（autorun + `test.sh` 2 斷言）

- `run_capture("ps")` 含 `init` 子串 ⇒ `ps PASS`。
- autorun：`trace(self,1)` → `getpid()` → `trace(self,0)`；`test.sh` run1 `check "STRACE"`（行內含 `id=12`，getpid 語意順帶驗）。
- `test.sh` 加 `check "ps PASS"` + `check "STRACE"`。

## 4. 非目標

- `top` 連續刷新、`kill -l` 訊號名、`dmesg` 等級、核心 perf counter。
- 跨權限 trace 限制（無 uid，先不做）。

## 5. 實作結算

- `run_capture("ps")` 初版 FAIL：`ps` 是 shell 內建，`exec_cmd` 子行程去找 `/bin/ps` 不存在。解法：`exec_cmd` 子行程在兩次 `exec` 都失敗後，若 argv 為裸 `ps` 則跑 `builtin_ps()` 再 exit（僅輸出型內建；`cd/export` 等狀態型仍 prompt-only）。
