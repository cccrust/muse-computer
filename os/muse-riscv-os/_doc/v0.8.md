# muse-riscv-os v0.8（已實作，`test.sh` 36 項全過）

方向：匿名 `mmap`/`munmap` + `sbrk` 收縮。純加法；on-disk 格式不動；COW fork 繼續延後（見 5）。

## 1. `unmap` 原語（核心 `mem`）

現況只有 map 方向（`map_one`/`alloc_map_user`），`frame::dealloc_frame` 有回收池但無人呼叫。

- `pt::unmap_page(root, va) -> Option<usize>`：走到 leaf；僅清除 U leaf（非 U 拒絕，防誤清核心映射），`sfence.vma`，回傳 PA。
- `mem::unmap_free_user(root, va, len)`：逐頁 `unmap_page` + `dealloc_frame`；未映射頁跳過（partial munmap 安全）。

## 2. `SYS_MMAP=30` / `SYS_MUNMAP=31`

- `mmap(hint, len, prot)`：僅匿名；`len==0` 或過大（>64MB）回 -1；`prot` 位：1=R、2=W（0 視同 R|W；X 一律拒絕，回 -1）。
- 配置策略：各進程 `mmap_base` 自 user stack 下方頂向下長（初始 `USER_STACK_TOP - STACK`）；`len` 上對齊 4K 後下扣、`alloc_map_user(R|W|U)`、回傳基址。`hint` 忽略（document）。
- `munmap(addr, len)`：`unmap_free_user` 對應範圍，回傳 0（空範圍亦 0；非 U/未映射頁跳過，不報錯）。
- `Proc` 加 `mmap_base: usize`、`brk_min: usize`：`finish_spawn` 初值（stack 下緣 / ELF brk）；`fork` 繼承（clone 側已有映射，不可重用同區）；`exec` 重置（位址空間已換新）。

## 3. `sbrk` 收縮

現況負增量直接回舊值（不縮不報錯）。

- `sys_sbrk(inc<0)`：`new = old+inc`；若 `new < brk_min` 回 -1；否則 `unmap_free_user(new, old-new)`、`brk=new`，回舊值（與正增量語意一致）。

## 4. 驗收（`usertests` + `test.sh` 1 斷言）

`usertests` 追加（既有 harness 印 `[TEST] ... PASS`）：

1. `mmap(0, 8192)` → 寫入魔數 → 讀回比對 → `munmap` → 再 `mmap` 同大小（回收池/重映射可用）→ 讀回零頁（dealloc 歸零語意）。
2. `sbrk(4096)` 寫入 → `sbrk(-4096)` 收縮成功 → 印 `[TEST] mmap PASS`。
- `test.sh` 加 `check "mmap PASS"`（run1）。

## 5. 非目標（仍不做）

- COW fork：要 PTE 引用計數 + 寫保護 fault 分發 + 缺頁路徑，風險高而 user address space 小（全拷貝夠用），v0.3 評估維持。
- `MAP_FIXED`、檔案映射、`mprotect`、demand paging、swap。
