# muse-riscv-os v3.9（主線：crates.io 端到端閉環）

## 0. 動機

v3.2 留的 deferred 項：「端到端 crates.io→guest 等第一個 guest
crate 出現」。主人已發布 `guest-args` / `guest-fmt` 0.1.0——
本版證明一條外部 crate 從 crates.io 下來、編進 guest 二進制、
裝進系統跑起來的完整鏈路。

## 1. 語義

- `tools/pkgrepeat/`：獨立 guest crate（自帶 `[workspace]`），
  二進制 `repeat`，依賴：
  - `guest-args = "0.1.0"`、`guest-fmt = "0.1.0"`（**從 crates.io**），
  - `user-lib = "0.1.1"`（**從 crates.io**；三個皆已上架，
    Cargo.lock 作證；update：已切換完畢）。
- `repeat <n> <word>`：`n` 經 `guest_args::parse_dec`，
  印 `1 word` … `n word` 各一行（行號經 `guest_fmt::fmt_dec`）。
  `n` 非法/缺失 → `repeat: bad count` exit 1；`n > 1000` 同
  （防跑飛）。`n = 0` → 無輸出 exit 0。
- registry：`/pkg/repeat/1.0/*` + index（`pkgbuild.build_package`
  啟動現編，fortune 同款；cargo 首次抓包要外網——test 環境有，
  寫死在這）。
- 非目標：user-lib 發布後把 path 換掉（屆時一行改動，另記）、
  第三方 crate 的版本升級跟隨。

## 2. suite（確定性設計：裝→跑→數行→刪）

```
ctr install 10.0.2.2 8091 repeat   → pkg-installed repeat 1.0
repeat 3 yo                         → 1 yo / 2 yo / 3 yo（三行）
ctr remove repeat                   → pkg-removed repeat
```

- test.sh +4 項（run1）：`pkg-installed repeat 1.0`、`3 yo`
  （只斷言末行——循環跑滿 3 次 + 格式化正確的直接證據）、
  `PKGLS repeat 1.0`、`pkg-removed repeat`。
- 手動：`repeat xyz`（bad count）、`repeat 0`（靜默 0）。

## 3. 非目標（→ v3.10+）

user-lib 發布後的依賴切換、多第三方 crate 共存、版本跟隨策略。
