# muse-riscv-os v1.0（規劃中，主線：SMP bring-up，4 核正確）

總綱見 `plan1.x.md`。本版只做「2 核能開機、排程正確、舊套件全綠 + smp 冒煙」，不碰效能。

## 1. 啟動（entry + HSM + per-hart 資源）

- `entry.S`：`csrr t0, mhartid`；hart0 走舊路（`boot_stack_top` → `rust_main`）；AP 跳 `_start_secondary`：以 hartid 算出 `boot_stacks[h]` 頂與 `tp=hartid`，調 `rust_secondary_main(hartid)`。
- `boot_stack`/`TRAP_STACK` 改 `[N]` 陣列（`MAX_HART=4`，與 `-smp 4` 對齊，不做動態化）。
- `sbi.rs`：`hsm_hart_start(hartid, start_addr, opaque)`（EID 0x48534D "HSM"，fid 0）+ 失敗回傳碼檢查（印出並 `wfi` 停住，勿靜默）；hart1/2/3 逐個喚醒。
- `rust_main` 尾端：MM/FS/PL-on（只配 hart0 部分）→ `task::init` → 逐核 `hsm_hart_start` → 本核進 `task::run_on(hart)`。
- `rust_secondary_main`：`println!("[SMP] hart<N> up")` → `task::run_on(hart)`（不重跑 init 系列，只進排程）。
- 順序鐵律：`disk::mount`、frame/heap 初始化、PLIC threshold 全域部分必須在放行 AP **之前**完成（之後皆為唯讀或鎖內操作）。

## 2. trap/PLIC/timer（per-hart）

- `trap::init_on(hart)`：`stvec`（全核同值）、`sie` 置 STIE+SEIE、`plic::enable_ctx(hart)`（context `2h+1`：enable UART+VIRTIO、threshold 0）、`uart::irq_enable` 只需一次（16550 IER 全域），`tx_enable` 同理。
- `timer::init_on(hart)`：`set_next()`（SBI timer 是 per-hart 的）；`TICKS: AtomicU64`（`tick()` 用 `fetch_add`）。
- trap 尾 `schedule_point` 取 `tp` 找本核 current；切換時把 TF 的 `kernel_sp` 重填為本核 trap 棧頂（遷移安全）。
- `set_yield_flag`/`take_yield_flag`、`current` 改 `[MAX_HART]` 陣列；`current_pid()` 語意改為「本核 current」（syscall 層呼叫點不動）。

## 3. 記憶體：RFENCE 接線

- `sbi.rs`：`rfnc_remote_sfence_vma(hart_mask, start, size)`（EID 0x52464E43 "RFNC"，fid 1；mask 全核）。
- 呼叫點（改完映射**後**）：`unmap_free_user` 尾、`protect` 尾、`task::exec` 換 root 後（舊 root 丟棄前；新 root 本核 activate 已全刷，只需遠端）。
- `activate()` 本地 `sfence.vma` 保留。

## 4. 併發審計清單（逐項打勾，不留 TODO 過版）

- [x] `blk::read`：CACHE 鎖內 `fetch`→改 drop 後重取（持鎖睡眠消除；`readahead` 同理改為查→取→裝）。
- [x] `virtio submit`：單 flight 加 `DRV_BUSY` spin 鎖（HDR/DATA/used 環跨核互斥）；completion wait 改純 poll（trap 內不可 sleep，`block_current` 在自旋中只會造成雙重入隊）。
- [x] `pipe`/`REG`/console/`uart ring`：console 輸出以整行/整 `write` 為單位加鎖（`console::write_bytes`）；`TX_ON` 轉 atomic。
- [x] `wake_locked`/`kill_with`：exactly-once 入隊（仍是某核 current 的任務不另 push，由該核 trap epilogue 推入；sched 鎖內序列化，兩種交錯皆恰一次）。
- [x] `run_on`：過濾拾取（跳過 reaped/zombie/他核持有，只取活 Runnable；`waitpid` 收割時 `queue.retain` 清殘留）。
- [x] `switch_to`：pick 重驗，無效則 idle（不關機）；queue 空不再關機（`exit` 時他核可能仍有 Running 任務），關機只走 `SYS_SHUTDOWN`。
- [x] `tp=hartid`：trap 進口以 trap 棧指標重算（`reaffirm_hartid`；trap.S 保留 user tp，任務遷移不再錯核；PLIC claim/complete 連帶修好）。
- [x] FG_PID → AtomicUsize（既有）；TICKS → AtomicU64（既有）；blk stats → AtomicU64；`VIRTIO_IRQ_SEEN`/`SCHED_ACTIVE` → atomic。
- [x] disk 掛載靜態：AP 放行前完成，之後唯讀（維持）。
- [x] `WFI` 說明：`run_on` 自旋不 `wfi`（SIE=0 無人喚醒）；idle 路徑 `wfi+SIE=1`（維持）。
- [x] boot hart 亦印 `[SMP] hartN up`（first-hart-wins 下 boot 核不定，test.sh 斷言 hart0–3 全到）。

## 5. user/test

- 新增 `user/smp_test`（workspace/mkfs/`embed.rs`/`run.sh`/`test.sh` 打包清單比照 `printenv` 前例）：fork 四個子行程各空轉 N 輪（`yield`，四核分攤）、父 `waitpid` 全收並校驗 code，印 `smp PASS`；sh autorun 加跑；`test.sh` run1 加 `check "smp PASS"` + `check "hart1 up"`/`hart2`/`hart3`。
- 其餘 47 項一字不動；若時序類（kill/bg/sleep）在 `-smp 4` 下抖動，先放寬窗口並記錄，不刪斷言（4 核 MTTCG 比單核慢，超時餘量要重估）。
