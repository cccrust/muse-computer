# muse-riscv-os v1.1（主線：per-CPU runqueue + 偷工作 + IPI 喚醒）

總綱見 `plan1.x.md §5`。v1.0 留下全域 queue + 大鎖（正確、但跨核搶鎖、任務亂遷移）；
本版切為 per-hart runqueue，idle 核偷工作，wake 順手 IPI 踢醒 idle 核。
鎖拆分（per-queue 鎖）刻意留給 v1.2：先證明放置+竊取正確，附爭用計數器為拆分提供依據。

## 1. 資料結構（`kernel/src/task/mod.rs`，大鎖維持）

- `Sched.queue: VecDeque` → `queues: [VecDeque<usize>; MAX_HART]`；`current/yield_flag` 不動。
- 新增 `idle: [bool; MAX_HART]`（idle_loop 進入/拾取任務時翻轉，sched 鎖內）。
- 新增 `STEALS: AtomicU64`（竊取計數，資訊用）；關機（`SYS_SHUTDOWN`）印 `[SMP] steals=<n>`。
- 不變量升級（v1.0 版逐條沿用，外加）：任務恰屬其一——`current[h]`、`queues[h]` 任一、或 neither；
  入隊操作一律判所屬：仍是某核 `current` 的只改狀態不 push（v1.0 exactly-once 擴大到 per-hart）。

## 2. 放置策略（全在 sched 鎖內，短臨界不變）

- `spawn/fork`：子任務進**父所在核**隊列（`current_pid` 的核；boot 期 init 進 boot 核）。
  `smp_test` 四子同隊——正好演示竊取擴散。
- `wake_locked`/`kill_with`：進**喚醒者所在核**隊列（數據熱、鎖順手）。
- `schedule_point`：先本地 `queues[h]` 掃描（沿用 v1.0 過濾：跳過 reaped/zombie/他核持有）；
  本地空 → 輪詢偷別核（一次偷一個，偷到即停）；皆空 → `idle_on_hart(h)`。
- `run_on`（開機）：本地 → 偷 → 自旋（沿用 v1.0，不 panic）。
- `exit::find_next`：本地 → 偷（`exclude` 語意不變）。
- `waitpid` 收割：四隊 `retain` 清殘留。

## 3. IPI（`sbi.rs` + `trap.rs` + `timer.rs` 不動）

- `sbi::send_ipi(hart_mask)`：EID `0x735049`（"sPI"），fid 0；回傳碼忽略（void 語意）。
- `trap::init/init_on`：`sie` 加 SSIP（bit 1）；`rust_trap_handler` 加 `scause==1`
  分支：`csrc sip, 2` 清 pending → 該核 soft-ack 原子旗置位 → `set_yield_flag`
 （epilogue 照常進 `schedule_point`）。
- 踢醒點 `kick_idle()`：鎖內算出 `idle[h] && !queues[h].empty()` 的 mask，解鎖後逐核
  `send_ipi`。呼叫點：`wake_*` 系（stdin/virtio/sleep/kill）尾、`fork`/`spawn` 尾。
  誤踢無害（soft 中斷只設 yield flag）；SIE=0 的核（kernel 自旋/`run_on`）pending
  留到下次進用戶態/idel 時送達。
- 開機自測：AP 全 `up` 後 boot 核對 AP 逐發 IPI，自旋等 soft-ack（timeout 回報
  `[TEST] ipi FAIL` 但繼續開機）；全到印 `[TEST] ipi PASS`。`test.sh` run1 加斷言。

## 4. RFENCE（v1.0 §3 欠帳，本版補齊；偷工作使遷移成常態，不補必出幽靈 fault）

- `sbi::remote_sfence_vma(hart_mask, start, size)`：EID `0x52464E43`（"RFNC"），fid 1。
  `start=size=0` 表全刷（SBI 語意，OpenSBI 有）。
- `pt::remote_flush_all()` 包裝：本地 `sfence.vma`（呼叫點多半已有）＋ 對其他核全刷
  （mask = 全核除本核；本核 id 由 `hartid()` 取——呼叫點皆為 trap/kernel 上下文，tp 有效）。
- 呼叫點（只做「活地址空間可被他核快取」的）：
  - `mem::unmap_free_user` 尾（munmap/sbrk-shrink，frame 回收重用，ASID 全 0 必刷）；
  - `task::exec` 換 root 後（新舊 root 同 VA 在他核 TLB 打架，ASID 全 0 必刷）。
  - `protect`：`spawn` 用在 fresh root（免刷），`exec` 已被上條覆蓋——呼叫方負責，註明。
  - `exit` 免刷：殭屍地址空間不回收 frame（沿用 v1.0，無重用即無殘留 hazard）。
- `activate()` 本地全刷維持。

## 5. user/test（`test.sh` 52+1=53 項）

- 既有 52 項一字不動；run1 加 `check "ipi PASS"`。
- `[SMP] steals=<n>` 關機印行：存在性不斷言數值（數值看擴散 health，人工判讀）。
- `smp_test` 不動（completion 斷言語意維持；spread 行維持資訊用）。
- run1 超時維持 120s（v1.0 實測剛好；若抖加餘量，不刪斷言）。

## 6. 驗收

- `./test.sh` 全綠，`qemu*.log` 零 `PANIC`/`FAIL`，連跑 2 輪。
- `ipi PASS` 穩定出現；`steals=` 出現（數值 >0 期望，抖動不卡版）。
- 舊版 playbook 沿用：DUP 探測器維持；幽靈 fault 先查 RFENCE 遺漏。

## 8. 實作血淚（必讀，v1.2 勿重蹈）

- **requeue 不可走 `enqueue_locked`**：`schedule_point` 的 requeue 擁有
  `current[h]`，而 `enqueue_locked` 的所屬檢查含自己——走它等於每次時間片都
  丟任務，全機幾秒內 drained 成寂靜。requeue 一律直接 push 本地隊（擁有者即
  自己，exactly-once 仍成立）；`Runnable`（窗內被喚醒）也要 push，只
  `Blocked/Zombie` 才 vacate（v1.0 單核沒窗所以沒爆，多核必爆）。
- **IPI 發給剛 `hart_start` 的核可能回 `-3`**（OpenSBI：STOPPED 態拒收，不
  pend）：開機自測對每核重送到 `rc==0`（5s 界）。`sip&2` 輪詢 ack 只能證明
  pend 過；trap 內 `csrc sip,2` 實測可清（`0x2->0x0`）。
- `run_on` 自旋（SIE=0）永遠收不到 IPI：自測 ack 另加 `poll_soft_ack()`；
  營運期 kick 靠 SIE=1 上下文（idle/用戶態）送達，另有 timer 10ms 保底。

- affinity syscall、per-CPU 負載均衡權重、write-back cache、virtio-net、journal。
