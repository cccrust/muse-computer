# muse-riscv-os v2.3（主線：docker 體驗三件套——一鍵 run、镜像、CPU 配額）

## 0. 動機

v2.0–v2.2 把隔離原語（root 視圖、pid 視圖、內存 cap）做完了，但用戶還
是要手動三步開機，也沒有镜像概念，更看不到 CPU 配額。本版把「能用」
補上：`ctr run` 一鍵、`pull` 镜像、CPU 上限。三件互相獨立（壞一件不
拖累另兩件驗收），共用 test 樁風格（host python、guest 主動、確定斷言）。

## 1. `ctr run <name> <prog> [args...]`（一鍵，約 60 行）

- 語意：root 不存在報錯（`pull` 先行，不玩隱式魔法）；`unshare()` →
  `fork()`（子建新 ns 當 pid 1，v2.1 語意）→ 子 `chroot(root)` +
  `chdir("/")` + `exec(prog, args)`；父 `waitpid` 收 code，原樣當
  `ctr` 的 exit code（`&&` 鏈可用，雖然 sh 還沒 `&&`）。
- prog 解析同 shell：含 `/` 照用（容器內絕對/相對皆可，chroot 後解析
  自動囚禁），裸名補 `/bin/`。
- stdio 繼承（console/pipe 照通）；不設 fg（後台語意 v2.4 議題）。

## 2. 镜像：manifest + tar 層 + registry 樁（不碰 overlayfs）

- 格式（標準優先，自造為恥）：manifest 純文本（一行一層文件名，`#` 註解），
  層 = ustar（只認 regular/dir，mode 除外全忽略——FS 無權限模型；host 端
  python `tarfile` 現成造層，零新工具）。
- `ctr pull <host> <port> <image>`：`GET /<image>/manifest` → 逐層
  `GET /<image>/<layer>` 存 `/tmp/lN.tar`（`mkdir /tmp` 按需）→ 順序解包
  進 `/ctr/<image>`（後層覆蓋）→ 刪 tar → 印 `[TEST] img PASS`
  （層數>0 且落檔>0；冪等重跑安全）。
- 下載複用 `wget` 二進制（fork+exec+wait，不重寫 HTTP client）。
  解包自寫 (~120 行：512 對齊、octal size、typeflag、NUL 名)。
- `tools/img_registry.py`（stdlib）：`:8091`，`/testimg/manifest` +
  `/testimg/layer1.tar`（啟動時用 `tarfile` 現包：`hello.txt` +
  host 讀 `target/.../release/echo` 灌進 `/bin/echo`——registry 讀 guest
  ELF 是故意的：測的就是跑起來的二進制）。
- suite（autorun 順序執行，確定性；樁常駐等，guest 主動故無時序脆弱）：
  `ctr pull 10.0.2.2 8091 testimg` → `ctr run testimg /bin/echo hello-from-image`
   → grep Console 的 `hello-from-image` + `[TEST] img PASS`（63+2=**65 項**…
   見 §4 計數）。

## 3. CPU 配額（cap-as-ceiling，會餓死不斷言 floor）

- 記賬：timer tick 给當前 task 的 cgroup `CG_CPU[cg]++`（atomics，
  Sched 外——ISR 上下文不拿新鎖；`current` 讀取沿用 trap 內既有模式）。
- 執行：100-tick 窗，`cg_pct[cg]`（默認 100；`SYS_CGSETCPU=50` 改）；
  pick（`pick_locked`/`find_next`/`run_on` 三處同規則）跳過超額任務，
  **除非無他可跑**（work-conserving：寧可跑超額的不閒置）。
  超額定義：`win_use*100 > pct*elapsed`（整數，無浮點）。
- 誠實聲明：持續滿載下被 cap 的組趨近 0 而非 5%（ceiling 語意）；
  floor/share（CFS 式）是 v2.4+ 議題。測 ceiling 不測 floor。
- 測試（順序斷言，非比率）：兩 hog 同跑（uncapped vs cap 5%），
  父 `waitpid(-1)` 第一個收到的**必須是 uncapped 那個**（15s 上限，
  超時/順序反了即 FAIL；同機背靠背，20× 速差面前抖動不夠看）。
  併進 `cgtest`（`cg PASS` 覆蓋，不新增 suite 項）。

## 4. 驗收

- `./test.sh` 全綠（**65 項**：63 + img PASS + hello-from-image），
  零 `PANIC`/`FAIL`，連跑 2 輪。
- 手動：`ctr pull … && ctr run …`、`cat` 下載物、`ps` 看 pid 1 容器。
- 補欠賬：`halt` 行加 `[CG] groups=N`（v2.2 doc 承諾過的，順手補）。

## 5. 非目標（→ v2.4+）

- overlayfs/union mount（展開式 rootfs 夠用到镜像語意完備那天）、
  registry 認證/摘要（裸 HTTP，寫死在這）、TLS、私有 registry、
  CPU floor/share（CFS）、跨容器網路隔離（netns/veth 大版）、
  `ctr stop/rm/ps` 生命週期管理、volume/bind mount。
