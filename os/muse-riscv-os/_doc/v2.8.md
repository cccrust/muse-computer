# muse-riscv-os v2.8（主線：`run --memory/--cpu/--weight`——配額接線）

## 0. 動機

v2.2/v2.3/v2.7 的內存 cap、CPU ceiling/shares 全在 kernel 里睡覺：
`ctr run` 一律 `cgcreate(0)`，容器「隔了視圖，沒隔資源」。
本版無新機制——純接線：把三個現成 syscall 掛到 `run` 旗子上。
（`ps` 看限額、`rm -f`、`exec`、log 落盤，往後排，見 §5。）

## 1. 語義

```
ctr run [-d] [--memory N] [--cpu P] [--weight W] <name> <prog> [args...]
```

- `--memory N`：幀數，`cglimit(cg, N)`。可帶 `K/M/G` 後綴
  （×1/256/262144 幀 = KB/MB/GB÷4KB；裸數即幀）。0 = 不限
  （= 不傳，同一語意）。例：`--memory 16M`。
- `--cpu P`：0–100，`cgsetcpu(cg, P)`。範圍外 ctr 直接拒絕
  （kernel 側是鉗制不斷言——靜默鉗制會騙人，寫死在這）。
- `--weight W`：1–1000，`cgsetshare(cg, W)`。範圍外 kernel 回 -1，
  ctr 原樣 loud 報錯（不預判，單一真相源是 kernel）。
- 不傳 = 不調用（root 語意延續：不限、不設、不加權）。
- 順序：root 探測 → prog 解析 → `cgcreate(0)` → 三設限（逐個驗回值，
  敗即 exit 1；槽位該漏就漏，v2.6 同紀律）→ unshare → fork →
  子 `cgenter` 第一（chroot 之前，v2.6 順序不動）。
- 成功行（沿用 markers 風格，test.sh 可 grep）：
  - `-d`：`detached <pid> mem=<f> cpu=<p> weight=<w>`
    （未傳的鍵照默認印：mem=0 cpu=100 weight=1——所見即所得，
    不是「實際查詢」（無 getter syscall），而是「請求即生效」
    紀律：三設限任一失敗 run 直接 abort，故印出的一定生效過）。
  - 前台：行為不變（exit code 直通），不添輸出（echo 類輸出歸 prog）。

## 2. suite（確定性設計：正向 markers + 負向行為）

- 正向（`life` 6 步的 run-d 換旗版）：
  `ctr run -d --memory 100000 --cpu 50 --weight 8 life /bin/linger 30`
  → `detached … mem=100000 cpu=50 weight=8`（解析+接線的直接證據；
  100000 幀≈400MB 遠大於 footprint，絕不咬人）。
  後續 ps/stop(`killed 2`)/rm 不動。
- 負向（限額真咬人，無時序）：
  `ctr run --memory 5 life /bin/sleeper 1`（前台）→ exec 映射
  文本（~13 幀）+ 棧（8 幀）+ 表 ≫ 5 幀 → `exec` 回 false →
  `ctr: exec failed` exit 127。test.sh 斷言該行**出現**
  （失敗路徑的陽性斷言；`init: exec sh failed` 是另一串，不碰撞；
  `[PROC] exec pid=` 是另一串，不碰撞）。
- test.sh +4 項（73+4=**77 項**）：
  `mem=100000`、`cpu=50`、`weight=8`、`ctr: exec failed`。
- 手動：`--cpu 999` 被拒、`--weight 0` 被拒（kernel 回 -1 透出）、
  `--memory 16M` 等價 `--memory 4096`（後綴數學，suite 不斷言，
  手動驗）。

## 3. 非目標（→ v2.9+）

- `ps` 顯示限額（要 getter syscall×3；目前成功行即真相）、
  `rm -f`、`restart`、`exec`、log 落盤/後台 stdio 重定向、
  人性化字節解析器擴充（目前 K/M/G 夠用；`KB/MB` 別名不加）、
  registry 認證、overlayfs、netns/veth、volume、IO 權重、
  層級配額 enforced、cgroupfs、OOM-killer、`pivot_root`。
