# muse-riscv-os v1.7（主線：guest online——主動 TCP + DNS + wget/curl）

## 0. 動機

v1.5 的網路是單向的（只能被連）。本版補上出方向：guest 主動建連、
解域名、抓檔案。配菜不另開：`ping` 已在 v1.6，DHCP 續砍（SLIRP 預設
網段十年不變，靜態 IP 再撐）。

## 1. 設計

### 1.1 ARP 泛化（`net/mod.rs`，現有單 gateway 表改小 cache）

- 現況：`gw_mac`/`arp_ok` 只認 10.0.2.2。改 4 表項
  `{ip, mac, valid}` + `pending {ip, req_at}`；`mac_for(ip)` 命中即回，
  未命中發 ARP（限速沿用 1s）回 WouldBlock。
- 路由：無（同子網假設；SLIRP proxy-ARP 全段，夠用；跨子網是 v1.8+ 議題）。
- UDP/TCP/ICMP 發包統一經 `mac_for`（原 `gw_mac` 直引處全改，約 4 處）。

### 1.2 TCP 主動 open（`net/tcp.rs`，只加分支不改架構）

- `connect(ip, port)` 在 TCP socket：ARP 未解回 `-2`（用戶重試，udpping
  前例）；ARP 就緒發 SYN，`SYN_SENT`，回 0（non-blocking connect，
  house WouldBlock 風格）。
- RX：`SYN_SENT` + SYN|ACK（ack==snd_nxt）→ 發 ACK → `ESTABLISHED` + 喚醒；
  RST → `CLOSED` + 喚醒。tick 重傳 SYN 沿用 SYN_RCVD 臂（合併條件）。
- `send` 在 `SYN_SENT` 回 `-2`（原 `-1` 改；未就緒≠錯誤）。
  其餘狀態機、重傳、關閉一字不動；simultaneous open 丟棄（註明）。
- `close()` 在 `SYN_SENT` 走既有 catch-all（RST+釋放）✓ 免改。

### 1.3 DNS client（`user-lib`，內核零新增，直接跑在 UDP 上）

- `dns_resolve(sockfd?, name, server_ip) -> Option<u32>`——為免改 syscall，
  在 user-lib 內自開 UDP socket（`socket/connect/send/recv/close` 現成），
  呼叫端只傳 `name` + `server`（預設 `10.0.2.3`，測服用 `10.0.2.2:15353`）。
  包格式：標準 query（RD=1，A類）、解析應答（壓縮指針必處理、CNAME 跟一跳、
  取首個 A）。超時重試 3 次（每次 2s）。
- 選 user-space 的理由：封包解析是純邏輯，進內核只會拖大 TCB 鎖；
  且 `#[cfg(test)]` 測不了 no_std 用戶碼，改放可測性於 host 單元？不——
  沿用 house 慣例：邏輯鏡像進 `kernel/src/lib.rs` 測（壓縮指針解析必測）。

### 1.4 wget + curl（行為區分，不是換皮）

- 共用：`user-lib` 小 helper（request 行組裝、`\r\n\r\n` 切頭、Content-Length
  讀取；約 60 行，兩 app 共用，免三倍除錯）。
- `wget host port path file`：存檔（覆寫），全收後校驗（200 + 長度吻合）
  印 `[TEST] wget PASS/FAIL`。參數全 literal IP（suite 不依賴外部 DNS）。
- `curl host port path`：stdout 傾倒 headers + body（`-i` 語意），同樣自校驗
  印 `[TEST] curl PASS/FAIL`。兩者差異即演示：存檔 vs 傾倒。
- `nslookup name [server]`：解完印 `name -> a.b.c.d`，自校驗印
  `[TEST] nslookup PASS/FAIL`。

## 2. QEMU/測試線（host 雙樁，無外部網路依賴）

- `tools/http_server.py`（stdlib）：`127.0.0.1:8090`，`/test.txt` 回固定
  內容（含 `muse-riscv-os` 標記供斷言），其餘 404。guest 經 `10.0.2.2:8090`
  來訪（SLIRP 回環，udpping 前例）。
- `tools/dns_stub.py`（stdlib，無三方）：`127.0.0.1:5353`，任何 A 查詢回
  `10.0.2.99`（TTL 60）；guest 以 `10.0.2.2:15353` 來問。
- sh autorun（sequential，確定性；server 樁常駐等待，guest 主動故無時序脆弱）：
  `wget 10.0.2.2 8090 /test.txt /dl.txt` → `curl 10.0.2.2 8090 /test.txt` →
  `nslookup test.local 10.0.2.2`（server 參數走 argv；見 1.3）。
- `test.sh`：run1 起雙樁（跑完殺）、`check` 三項（59+3=**62 項**）。
  斷言只認 guest 側 marker（house 慣例）；python 側失敗另 `|| PASS=0` 雙保險。

## 3. 驗收

- `./test.sh` 全綠（62 項），零 `PANIC`/`FAIL`，連跑 2 輪。
- `wget/curl/nslookup PASS` 穩定；手動 `wget 10.0.2.2 8090 /README /f && cat /f` 可玩。
- 真外網（host 有網時 `wget example.com ...`）為手動加分項，不進斷言。

## 4. 非目標（→ v1.8+）

- DHCP（靜態續行）、TLS、HTTP/1.1 keep-alive/chunked（`Connection: close`
  到底）、IPv6、TCP 同時開、擁塞控制（沿用 v1.5 立場）、DNS TCP fallback/
  完整 CNAME 鏈（跟一跳為止）。

## 5. 實作血淚（v1.8 讀）

- **host 埠先查誰佔著**：DNS stub 首選 5353 在 macOS 上是 mDNSResponder 的，
  bind 直接炸——改 15353。教訓：stub 埠一律開跑前 `bind` 探活，
  失敗要大聲（這次是靜默 timeout，查了半天）。
- **SYN_SENT 是未就緒不是錯誤**：`send` 在握手期回 `-2`（重試）而非 `-1`，
  否則 client 首包永遠失敗。WouldBlock 語意是全系統契約，新增態必對號入座。
- **accept 拆 peek+commit**：fd 滿時已標記的子 TCB 會洩漏（無 fd、無人收）；
  先 peek、fd 落定再 commit。
- **手動冒煙別在 t=0 餵 stdin**：autorun 的 console reader 會啃掉 early
  input（`ping` 變 `/bin/ng` 事件）；等 prompt（poll `^sh\$ `）再送。
