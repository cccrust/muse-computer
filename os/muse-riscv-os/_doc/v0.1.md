# muse-riscv-os v0.1

RV64 裸機 Unix-v6-like OS，第一個可開機、可測試版本。詳見 `_doc/plan.md`（當初規劃）。

## 範圍

- 平台：QEMU `virt` + OpenSBI default bios，S-mode kernel（`0x80200000`），全 Rust、零外部依賴
- SV39 MMU：三層頁表（PTE V/R/W/X/U/A/D）、每進程獨立 `MemorySet`、核心恆等映射、`satp MODE=8`
- 多進程：`fork`（位址空間全拷貝）、`exec`（ELF 重載）、`wait`/`exit`、`getpid`/`sleep`/`kill`/`sbrk`，RR 排程 + 10ms timer 搶佔
- Syscall（xv6 相容編號子集）：`open/read/write/close/dup/pipe/chdir/mkdir/unlink/fstat` stub 等 20 支
- 檔案系統：**RamFS（純記憶體）**——路徑樹（`/bin/*`、`/README`、`/`、`/bin`、`/etc`）、`O_CREATE`、擴檔寫入、`mkdir`/`unlink`、pipe（ring-buffer，支援 `sh | grep`）
- virtio-blk：僅 probe（認得 `0x10001000` block device，印 PASS），`fs.img` 由 `tools/mkfs` 產生但 kernel 尚未掛載/解析
- 使用者程式（獨立 ELF，`ecall` 進核心）：`init`、`sh`（支援 `|`，開機自動跑 `usertests`）、`ls`、`cat`、`echo`、`grep`、`fork_test`、`pipe_test`、`usertests`

## 使用

- `./run.sh`：編譯 user ELF → mkfs → 編譯 kernel → objcopy → QEMU 互動 shell（`ls`、`cat /README`、`echo hi | grep hi`、`usertests`）
- `./test.sh`：host 單元測試（PTE/VPN/frame mock/RR queue）+ 交叉編譯 + 25s QEMU 斷言（`SV39 enabled`、`spawn init`、`fork PASS`、`pipe PASS`、`usertests PASS`、`VIRTIO`、無 `PANIC`）→ `ALL TESTS PASSED`，exit 0

## 已知限制（v0.2 候選）

1. 無持久化 FS：重開機自建檔案消失；virtio-blk 讀寫 + on-disk layout（superblock/inode/bitmap）掛載取代 RamFS
2. `fork` 全拷貝（無 COW）、無檔案權限/uid、`fstat/link` 為 stub
3. `ls` 為固定清單（無 readdir syscall）、shell 重定向 `>`/`<`、`&` 尚未實作
4. `test.sh` QEMU stdin 固定接 `/dev/null`（ interactive tty + pipe 會讓 QEMU 靜默，見修復紀錄）
