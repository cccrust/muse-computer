# muse-riscv-os v3.5（主線：volume——容器數據正規路）

## 0. 動機

plan2.x §8 原話：「持久數據進出容器的正規路；目前靠 hardlink
與整盤持久」。包（v3.x）和容器（v2.x）都齊了，數據卷是最後一塊
拼圖。本版只做 bind 語意，不做驅動/配額/遷移。

## 1. 語義

```
ctr volume create <v> | ctr volume rm <v> | ctr volume ls
ctr run [-d] ... [-v V:C]... <name> <prog> [args...]
```

- volume 就是 `/vol/<v>/` 目錄（與 `/ctr` 平級，不隨容器生死；
  `rm` 遞迴刪，非空也刪，docker 同款）。`ls` 印 `VOL NAME` +
  `VOL <v>` 行。名規則沿用 `valid_name`。
- `run -v V:C`（可重複，上限 4；`-v SPEC` 與 `-v=SPEC` 兩種寫法，
  quota 旗子同款）：C 是 jail 內絕對路徑（必須以 `/` 起頭）。
- kernel：per-proc mount 表（4 ×（mp[64]，tgt[64]），fork 繼承，
  exec 保留——同 proc）。新 syscall `SYS_MOUNTVOL=56`：
  `mount_vol(mp_abs, tgt_abs)`（syscall 內先 `resolve_for` 再驗）：
  tgt 必須存在且是 dir（`stat` kind 2），mp 不存在則單層 mkdir
  （父目錄必須存在），mp 尾 `/` 全部掐掉；表滿 → -1。
- `resolve_for`：jail 解析後做最長前綴改寫（`/` 邊界：`/data`
  不配 `/data2`；全等也配）。`nmounts==0` 時與舊路徑逐位元同
  （熱路徑多一次空掃，50ns 級，接受）。
- child 順序：`cgenter` → mounts → `chroot` → `chdir` →
  dup2s → `exec`（mount 要 host 視角，必須在 chroot 前）。
- per-proc 表隨 proc 消亡而消失：無 umount、無洩漏（設計即如此）。
- 已知 wart：`getdents` 對缺失路徑回 0 而非 -1（缺目錄 vs 空目錄
  不可分）——volume 存在探測走父目錄列表（`vol_exists`），不直接
  探路徑。舊代碼（`run`/`rm` 的 image 探測）同病，但後續 loud
  失敗兜底，本版不動它們。
- 已知缺口：`ctr exec` 不帶 volume 綁定（讀不到目標的表；
  exec 是排錯路，v3.5 不補）。

## 2. suite（確定性設計：外面寫，裡面讀）

```
ctr volume create data1                        → vol-created data1
(sh 直接寫 /vol/data1/greet.txt = "hi-vol"，/WD/F 前例)
ctr volc                                       → ready /ctr/volc（組裝 root）
ctr run -v data1:/data volc /bin/cat /data/greet.txt → hi-vol
ctr volume ls                                  → VOL data1
ctr rm volc                                    → removed volc
ctr volume rm data1                            → vol-removed data1
```

- 反向（裡面寫外面看）本版不斷言：bind 結構對稱，缺的是寫側
  工具（echo 重定向在 autorun 里不好擺），不是語意。
- test.sh +5 項（run1）：`vol-created data1`、`VOL data1`、
  `hi-vol`、`removed volc`、`vol-removed data1`。
- 手動：`-v` 缺冒號/相對路徑拒絕、tgt 不存在拒絕、表滿（4 個後）
  拒絕、mount 嵌套（`-v a:/x -v b:/x/sub` 最長前綴贏）。

## 3. 非目標（→ v3.6+）

volume quota、volume driver、跨宿主遷移、exec 帶綁定、
mount 進 `/bin` 等系統路徑的保護（扁平模型，寫死）。
