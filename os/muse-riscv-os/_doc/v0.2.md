# muse-riscv-os v0.2 規劃（未實作）

目標：把 v0.1 的 RamFS 換成**可持久化的磁碟檔案系統**，其他順手補齊 v0.1 留下的 stub。核心、進程、syscall 分發、測試框架都不動。

## 1. 主線：block-backed FS 取代 RamFS

### 1.1 virtio-blk polling 讀寫（`kernel/src/fs/virtio.rs` 擴充）
- 現況只有 probe（讀 magic/ver/type）。補 MMIO 控制：device status（ACK/DRIVER/OK/FEATURES_OK）、queue（desc/avail/used，配 1 個 virtqueue，depth 8 即可）、REQ OUT header + data + status IN 三段描述符。
- 先只做同步 polling（送 request → 忙等 used idx 推進），中斷後再說；每次請求 1 個 sector（512B），介面：`blk_read(lba, &mut [u8;512])` / `blk_write(lba, &[u8;512])`。
- 開機自測沿用：讀 LBA0 magic（見 1.2）並印 `[TEST] virtio-blk RW PASS`（讀寫同一塊並還原）。

### 1.2 on-disk layout（沿用 `tools/mkfs` 產生，kernel 唯讀掛載 + 讀寫）
- 保持簡單、固定大小，沿用 v0.1 `MUSEFS01` 魔數以便相容過渡：
  - LBA0: superblock（magic、block size=512、塊總數、inode bitmap 位置/大小、data 區起點、root inode 號）
  - 其後：block bitmap（1 block 起跳）、inode 區（每 inode 64B：kind、size、direct[8]、indirect1）、data 區
- 路徑解析只支援絕對路徑 + 單層目錄遍歷（`/`、`/bin` 先夠用）；檔名定長 28B 存於目錄 data block（`name[28] + inode_no`）。
- `mkfs` 改寫：不再是 concat 頭，而是按上述 layout 把 9 個 user ELF + `/README` 寫入並建立 `/bin` 目錄項；`fs.img` 維持 4MB。

### 1.3 VFS 層（`kernel/src/fs/mod.rs` 改接）
- `ramfs::{read_file,write_file,read_at,write_at,...}` 呼叫點不動，底下換成 block cache：
  - block cache：8–16 槽、每槽 512B、dirty bit、單調時鐘淘汰（先求有，不做併發，沒有 SMP 問題）。
  - 寫入採 write-through（簡單、斷電一致性先不保證 journel，文件註明）。
- 開機流程改為：`virtio::probe` → `blk 自測` → `mount(/dev/vda)` 成功才 `fs::init`（失敗則 fallback RamFS + 印警告，保住開機）。
- `/bin/*` 不再需要 `embed.rs` 內嵌（體積大），改由磁碟載入；`embed` 保留為 fallback（mount 失敗時用），`exec` 優先讀磁碟。

### 1.4 驗收（加進 `test.sh`，不動既有斷言）
- 新增：`disk RW PASS`（LBA 迴環）、`persist BAR`——測試法：user 程式寫 `/TESTDATA` → 正常關機（`shutdown` syscall，見 2.2）→ QEMU 二次啟動同一 `fs.img` 讀回比對。`test.sh` 跑兩次 QEMU（第一次寫，第二次讀），不斷言時序只斷言內容。
- `qemu.log` 保留，第二次啟動記 `qemu2.log`。

## 2. 順手補齊（小、獨立、可個別跳過）

1. `readdir` syscall + `ls` 改走目錄遍歷（取代固定清單），斷言 `ls PASS` 不變。
2. `shutdown`/`reboot` syscall（SBI SRST），供持久化測試正常關機；shell 內建 `halt`。
3. shell 重定向 `>`/`<`（單檔、覆寫模式即可），`&` 背景仍可再延。
4. `fstat` 回填 size/kind（`ls -l` 先不做）；`link` 留空。
5. `test.sh` 把 `file.locking` 改回預設 on（v0.1 為防誤用設 off；持久化測試跑兩次 QEMU，需確認前一次已退出，否則鎖錯誤要能清楚失敗而非靜默）。

## 3. 非目標（明確不做）

- journal / crash consistency、COW fork、多 hart SMP、網路、真正的 Unix 權限/uid。
- indirect2 / 大檔（indirect1 + 8 direct 上限約 132KB，user ELF 最大 61KB，夠用）。

## 4. 預估動工順序

1. virtio queue R/W + LBA 自測（host 測不了，全靠 QEMU log；先只讀 LBA0 magic）。
2. mkfs 新 layout（host 端可 `cargo test` 驗 round-trip：pack → parse）。
3. block cache + inode 讀寫 + mount fallback。
4. exec 改讀磁碟、`embed` 降為 fallback。
5. 持久化雙啟動測試 + `test.sh` 新斷言。
6. 第 2 節小項。
