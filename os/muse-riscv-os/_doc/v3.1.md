# muse-riscv-os v3.1（主線：`depends`——依賴閉環）

## 0. 動機

v3.0 只裝單包；真實包（`farewell` 想用 `hello` 的東西）需要依賴。
本版加 manifest `depends:` + guest 拓撲安裝。版本約束只認 `=`。

## 1. 語義

- manifest 行：`depends: a b=1.0 c`（空格分隔，每項 `name`
  或 `name=ver`）。v3.0 已忽略未知 key——舊 binary 讀新 manifest
  不會炸（只是不裝依賴；混版不保證，寫死在這）。
- `ctr install`：對包自身 + 傳遞依賴做 DFS 後序安裝（依賴先裝）。
  - 已安裝：跳過，但 `=ver` 與 db 版本比對——不符 → 
    `ctr: version mismatch` exit 1。
  - 棧上重複（ depth cap 8，更深 → `ctr: dependency depth`）→
    `ctr: dependency cycle` exit 1。
  - 任一依賴失敗 → 整單失敗 exit 1（之前裝好的依賴**留下**：
    各自獨立追蹤，apt 同款；`remove` 逐個清）。
- 安裝成功把 manifest 原文存一份進 `/pkg/<name>/manifest`
  （remove 反查用；多花一次寫，不佔新路）。
- `ctr remove`：掃 `/pkg/*/manifest` 的 depends——有人依賴 →
  `ctr: needed by <other>` exit 1（第一個找到的；自掃跳過）。
  無依賴問題才走 v3.0 流程。
- 非目標：版本範圍（`>=` 等）、`upgrade`、自動清孤兒、
  依賴的依賴的版本合併（鑽石依賴以第一次安裝為準）。

## 2. suite（確定性設計：依賴+循環+保護）

- 新包 `farewell`（echo ELF 作 `bin/farewell` + `farewell.txt`，
  manifest `depends: hello=1.0`）與自循環包 `loopy`
 （`depends: loopy`）：
  ```
  ctr install 10.0.2.2 8091 farewell → pkg-installed farewell 1.0
  ctr list                             → PKGLS hello 1.0 + PKGLS farewell 1.0
  farewell farewell-marker              → farewell-marker
  ctr remove hello                     → ctr: needed by farewell（拒絕證明）
  ctr install 10.0.2.2 8091 loopy     → ctr: dependency cycle
  ctr remove farewell                  → pkg-removed farewell
  ctr remove hello                     → pkg-removed hello
  ```
  （v3.0 段已把 hello 裝了又刪，db 是乾淨的——依賴鏈從零驗起。）
- test.sh +7 項（run1）：`pkg-installed farewell 1.0`、
  `PKGLS farewell 1.0`、`farewell-marker`、`needed by farewell`、
  `dependency cycle`、`pkg-removed farewell`、`pkg-removed hello`。

## 5. 已知 wart（v1.x TCP，不在本版修）

- 現象：連續 7 次 fetch 後第 8 次 `connect` 失敗，且 SYN 到不了
  server（registry accept 日誌證明）——`NSOCK=8` 耗盡：TCP close
  的 slot 要等 FIN 握手排空（最長 30s `CLOSE_TIMEOUT`），加上
  webserver 常駐 listen，burst 直接見頂。
- 本版處置：`NSOCK` 8→32（provisioning；`Sock` 小，約 4K .bss）。
  排空仍是 30s 上限，但 suite 級 burst 再也碰不到頂。
- 真修（以後）：纯 FIN 的 RTO 重傳（`tcp_tick` 只重傳非空
  `unacked`，FIN-only close 卡住只能等 30s）、或 timer tick 順便
  harvest RX。動 TCP 前先想清楚，這裡只記錄證據。
