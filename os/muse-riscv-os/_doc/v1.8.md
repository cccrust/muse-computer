# muse-riscv-os v1.8（主線：journal TX batching，單 syscall 原子存活；配菜 monotonic time）

## 0. 動機

v1.6 的 journal 保的是 512B sector——跨 sector 的寫（4K 頁、追加+改 size）
照樣 torn（標準 ordered-mode 語意，但我們說好要更好）。本版把原子單位
拉到 syscall：一次完成的寫入，斷電後要麼全活、要麼全無。配菜是單調時鐘
（牆鐘硬體在 virt 上不存在，不裝；monotonic 是 TLS/超時的地基，早拿）。

## 1. 設計（`fs/jnl.rs` 內改格式，`disk.rs` 不動）

### 1.1 TX 與 commit 記錄

- A-record 加 `tx u32 @20`（舊記錄該處全零 → `tx=0` = legacy，天然相容）。
- Commit 記錄：獨立 magic `JRNc`，`{gen, tx, count, crc(tx,count,zero)}`，
  佔 1 sector（與數據槽同一環地址空間？不——commit 另起序號空間會亂
  seq 排序；實作：commit 占一個普通槽位，`lba = 0xFFFF_FFFF` 標記，
  replay 認 magic 區分。槽位計算不變）。
- `JLOG` 加 `{depth, id, count, next}`：`begin()`（depth++，首層配新 id）、
  `commit()`（depth--；歸零且 count>0 才寫 commit 扇區，否則靜默收攤——
  console/pipe 寫入零開銷）。`record()` 蓋當前景 `id`（0 表 legacy）。
- 括號點：`handle()` 分發處包 WRITE/OPEN/MKDIR/LINK/UNLINK 五個
  （用戶可見原子單位 = syscall；syscall 互不嵌套，depth 保險絲以防萬一）。

### 1.2 重放分組

- 有效記錄按 `tx` 分組：`tx=0` 照舊直 apply；`tx!=0` 需同 tx 的 commit
  存在 **且** 成員數 == `commit.count`，缺一全跳（原子性正在於此）。
- 全體 apply 項（legacy + 已提交 TX 成員）按 seq 全局排序後 raw 寫回；
  同 lba 後寫勝（seq 即真實時序）✓。冪等性維持。
- crash 切面新增一種：commit 寫一半 → magic/crc 壞 → 整 TX 跳過
  （home 全是舊版；write 未 ack ✓）。其餘沿用 v1.6 分析。

### 1.3 測試升級（同一個 crashwrite 越測越強）

- `crashwrite` 改回 4K 頁（16 頁 = 64KB；v1.6 降級到 sector 是當時的保證
  邊界，現在保證拉到 syscall，測試跟著升級）。一頁 8 sectors 同一 `write`
  同一 TX——torn 即 FAIL。
- host 單元（`lib.rs` 鏡像）：commit 缺失/成員不齊跳過、跨 TX 同 lba 取
  後者、legacy(tx=0) 直 apply。
- suite 項數不變（`crash PASS` 同名斷言變嚴格；59 項維持）。

## 2. 配菜：monotonic time（`SYS_TIME = 44`）

- virt 無牆鐘 RTC 硬體，不偽造 wall clock。回 `timer::ticks()/100` 秒？
  不——回 ms（ticks，10MHz time CSR 直讀，`now_ms = ticks/10000`），
  u64……RV64 `isize` 64 位夠裝。`user-lib::uptime_ms()`。
- 自測：两次调用夹一次 `sleep`，断言严格递增 + 差值下界，印
  `[TEST] time PASS`；sh autorun 跑一次（59+1=**60 項**）。
- 非目標：牆鐘、時區、NTP、date 指令（v1.9+ 議題）。

## 3. 驗收

- `./test.sh` 全綠（60 項），零 `PANIC`/`FAIL`，連跑 2 輪。
- `crash PASS`（4K 版）穩定；`time PASS` 穩定；`journal replayed` 穩定。
- 舊 image 相容：v1.6 寫的盤（無 tx 欄位）掛載重放正常（tx=0 路徑）。

## 4. 非目標（→ v1.9+）

- demand paging（大版）、signals、TCP 主動端之外的傳輸強化、DHCP、
  write-back、ASID、affinity、OOM 優雅化（v1.9 候選池，另議）。

## 5. 實作血淚（v1.9 讀）

- **commit 也要佔 seq**：重放按 seq 全局排序，commit 記錄不佔位會讓
  排序與真實時序脫鉤（同 lba 跨 TX 取錯版本）。所有進環的東西一律取號。
- **chunk valve 的計數放在同一把鎖內一次算完**：中途 drop/re-lock 再讀
  會遇到借用與計數雙重麻煩；先算好（pending tuple）再動手。
- **crc 綁定凡寫必綁**：A 記錄綁 (seq,lba,tx)，commit 綁 (tx,count,marker)，
  少綁一個，torn 混合就多一條活路。lib.rs 鏡像同步改（簽名一動兩邊動）。
- **括號點選 syscall 不選 disk 函數**：用戶可見原子單位才是契約；
  disk 函數嵌套調用，括號放錯層等於沒括。
- **§11 慢 host 三件套**：prompt 門控 stdin、marker 輪詢 180s、sleep 25
  積累版本；失敗先看 load，再看是否同點重現（本版吃過一次 120s 不夠的虧）。
