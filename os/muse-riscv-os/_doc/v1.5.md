# muse-riscv-os v1.5（主線：TCP + 靜態 web server 範例；只要夠用的 TCP）

## 0. 動機與範圍鐵律

v1.3 證明 guest↔host 通了（UDP）。本版把傳輸補到 TCP——但只做到
「跑得動靜態 web server」的子集：三次握手、順序傳輸、超時重傳、半關閉；
**無擁塞控制、無視窗縮放、無 keepalive、無亂序重組（亂序包丟棄靠重傳補）**。
TCP 本來就是整整一版，這份文件把「整版」的邊界釘死，免得做成第二個內核。

## 1. 設計（`kernel/src/net/tcp.rs` 新檔，ARP/UDP 不動）

### 1.1 TCB 與狀態機

- `TCB { state, lport, rip, rport, iss, snd_una, snd_nxt, rcv_nxt, snd_wnd,
  rx: VecDeque<u8>, backlog: Option<pending>, rto_at: u64, retries: u8 }`，
  全在既有 `NET` 大鎖下（v1.4 判決：不拆鎖；net 程式碼禁自創鎖序）。
- 狀態：`LISTEN → SYN_RCVD → ESTABLISHED → (CLOSE_WAIT|FIN_WAIT1) →
  LAST_ACK/CLOSING → CLOSED`；主動 open 不做（web server 只要被動）。
  `TIME_WAIT` 不實作（關閉直接 `CLOSED` + 2MSL 內同四元組拒絕——SLIRP
  測試環境埠號不重用，夠用；註明）。
- ISS：`timer::ticks()` 混合 lport（可預測但測試環境唯一，夠用）。

### 1.2 收包（RX ISR 路徑，`parse_frame` 分流 IP proto 6）

- 驗證：IP 頭 + TCP 頭長度、dst IP/連接埠命中 TCB（LISTEN 通配 rport）。
- `LISTEN` + SYN → 建半連接（backlog 1 格，滿則丟棄靠重傳）、回 SYN+ACK、
  喚醒 `accept` 者（`BLOCK_NET` 沿用）。
- `SYN_RCVD` + 正確 ACK → `ESTABLISHED`；數據按 `rcv_nxt` 收（亂序直接丟，
  對端超時重傳；重複 ACK 照回當前 `rcv_nxt`）。
- `ESTABLISHED`：ACK 推進 `snd_una`（清重傳）；數據進 `rx`（cap 32K，
  滿丟包靠對端重傳）；FIN → `CLOSE_WAIT` + 喚醒 reader（EOF 語意見 1.4）。
- RST 直接進 `CLOSED` 喚醒兩端（讀寫皆錯）。

### 1.3 發包與重傳（無擁塞控制，固定行為）

- `send` 切 MSS 1460 分段，`snd_nxt` 推進；每段記 `rto_at = ticks+20`
  （200ms）、`retries=0`。
- 重傳驅動：`net::tick()`（timer tick ISR 每 10ms 調一次，沿用既有 trap 路徑；
  只掃有未確認段的 TCB），超時重發首個未確認段，`retries>5` 發 RST 進
  `CLOSED` 喚醒兩端。RTO 固定不做 RTT 估算（註明；區域 SLIRP 穩定夠用）。
- 關閉：`close()` 在 `ESTABLISHED` 發 FIN 進 `FIN_WAIT1`（對端 ACK→`FIN_WAIT2`，
  對端 FIN→`CLOSING`→ACK→`CLOSED`）；`CLOSE_WAIT` 下 `close()` 發 FIN 進
  `LAST_ACK`，對端 ACK 即 `CLOSED`。TCB 資源隨 socket 釋放。

### 1.4 Checksum

- TCP checksum 必算（含 pseudo-header；沿用 `ip_cksum` 模式另寫
  `tcp_cksum`）。RX 校驗錯直接丟（註明：QEMU/SLIRP 皆正確計算，夠用）。

## 2. Syscall（3 個新 + 2 個沿用擴充）

- `SYS_BIND = 41(fd, port)`：UDP/TCP 共用（UDP 綁定固定源埠；TCP 進 LISTEN
  前置條件）。已用埠回 `-1`。
- `SYS_LISTEN = 42(fd)`：TCP socket 進 `LISTEN`。
- `SYS_ACCEPT = 43(fd)`：有完成握手者回新 fd（子 socket 繼承四元組，
  父保持 LISTEN 可再 accept；沿用 16-fd 表，滿回 `-2` WouldBlock？不——
  fd 滿是硬錯回 `-1`；無連接才是 `-2`）。
- `SYS_SOCKET = 37` 加 type（`a0`：0=UDP 沿用，1=TCP；舊 user-lib
  `socket()` 傳 0，行為不變）。
- `SYS_SEND/SYS_RECV` 打通 TCP：send 推段（窗口滿回 `-2`）；recv 從 `rx`
  拷貝、空回 `-2`、`CLOSE_WAIT` 且排空回 `0`（EOF）；`CLOSED` 回 `-1`。
- `close()` 沿用：TCP 發 FIN（§1.3）後釋放 TCB（`LAST_ACK` 等待由對端 ACK
  在 ISR 完成，無需持有資源——TCB 進獨立完成表？簡化：`close` 在
  `ESTABLISHED` 發 FIN 後**保留最小關閉狀態**（遠端四元組+snd_nxt）直到
  ACK 到或超時，socket fd 立刻可重用；註明這是最小實現）。

## 3. 範例：`user/webserver`（建構在 TCP 上的靜態檔 server）

- `socket(TCP)` → `bind(80)` → `listen()` → 迴圈 `accept()`：
  `recv` 讀請求頭（讀到 `\r\n\r\n` 或 2K 上限）→ 解析 `GET /path`（只認
  絕對路徑、拒 `..`，其他方法/路徑回 400/404）→ `open`+`read` 全文
  （上限 64K，超過回 413——ramfs 小檔為主，夠用）→
  `send("HTTP/1.0 200 OK\r\nContent-Length: N\r\nContent-Type: text/plain\r\n\r\n"+body)`。
- 首個有效 GET 服務完印 `[TEST] web PASS`（test.sh 斷言語據），之後常駐
  繼續服務（手動 `webserver &` 可玩；`halt` 關機即回收）。
- sh autorun 用 `spawn_one` 背景啟動（`run_one` 會等，不可用）。

## 4. QEMU/測試線

- QEMU 行加 `hostfwd=tcp::8080-:80`（與既有 user netdev 合併；
  run1–5/run.sh 全加，`SKIP` 語意不變——無網卡時 server `bind` 照常，
  只是 host 連不進來）。
- `tools/web_fetch.py`（host 端）：連 `127.0.0.1:8080`，發
  `GET /README HTTP/1.0\r\n\r\n`，讀到對端關閉或 5s 超時；斷言狀態行
  `HTTP/1.0 200` 且 body 含 `muse-riscv-os`；成功 exit 0，否則非零
  （`test.sh` 接 `|| PASS=0`；重試連接直到 30s，SLIRP 首連慢）。
- `test.sh`：run1 起 server（已有 autorun 背景啟動，無需另起）、跑
  `web_fetch.py`（失敗 `PASS=0`）、`check "web PASS"`（56+1=**57 項**）。
- 驗收：全綠，零 `PANIC`/`FAIL`，連跑 2 輪；`web PASS` 穩定；手動進 shell
  跑 `webserver &` + host `curl localhost:8080/README` 可玩。

## 5. 非目標（→ v1.6+）

- 擁塞控制（reno/cubic）、SACK/視窗縮放/RTT 估算、keepalive、TIME_WAIT
  完整語意、主動 open（guest 作 client）、DNS/DHCP、TLS、多並發壓力
  （server 單連接序列服務；backlog 1，夠演示）。

## 6. 實作血淚（v1.6 讀）

- **TCP checksum 的 0 映射只能用在生成側**：`0 -> 0xffff` 是 UDP「無校驗」
  慣例；寫進共用的驗證函數會讓**所有合法包驗證失敗**（靜默丟 SYN，
  pcap 上只看到單向 SYN storm）。對質工具：host 端 python 重算同包。
- **Ethernet padding 不屬於 TCP 段**：校驗/解析長度取 IP total-length，
  不取幀長（曾差 2 個位元組）。
- **BLOCK_WAIT 改語意後，所有「輪詢式 wait」都要換 WNOHANG**：
  `reap_poll` 用 blocking wait 會被不死的背景 child（webserver）睡死，
  prompt 停在 `read_edit` 之前、halt 字節爛在 UART ring。本版只中一個，
  下次加常駐行程時記得掃一遍。
- **測 SUT 內 server 必須背景跑 QEMU**：timeout 殺掉的機器沒法 fetch；
  run1 改 bg + poll（server 就緒→fetch→等 autorun 收尾→kill），預算另計。
