# muse-riscv-os v3.0（主線：`install/remove/list`——單包閉環）

## 0. 動機

v2.3 的 `pull` 證明了 guest 裝軟體的整條路（registry → wget →
ustar 解包 → 跑起來）。v3.0 把這條路收成 apt 式三件套：
`install/remove/list`。無依賴（那是 v3.1），第一批包是內建程式
重包（echo ELF 改名裝，零外部依賴）。

## 1. 語義

```
ctr install <host> <port> <pkg>   # argv 順序同 pull
ctr remove <pkg>
ctr list
```

- 包格式（plan3.x §3）：ustar layer + manifest。manifest 例：
  ```
  # pkg hello 1.0
  name: hello
  version: 1.0
  hello.tar
  ```
  解析規則：`#`/空行跳過；含 `:` 的行是 `key: value`
  （v3.0 只讀 `name`/`version`，未知 key 忽略——v3.1 `depends:`
  的前向兼容）；其餘行是 layer 檔名（cap 8，pull 同款）。
  manifest 自身 ≤2048B（pull 同款）。
- `install`：`GET /pkg/<pkg>/manifest` → 逐層下載 → 解包進
  `/pkg/<name>/` store（`untar` 原樣複用）→ 預檢 store/bin 下
  每個名字在 `/bin/` 不存在（已存在 → `ctr: shadows /bin/<f>`
  exit 1，防 clobber + remove 誤刪）→ hardlink 進 `/bin`
  （assemble 招式）→ `/pkg/db` 追加 `name version`。
  成功行：`pkg-installed <name> <version>`。
  已安裝 → `ctr: already installed` exit 1（重裝/upgrade 非目標）。
  解包後任一步失敗 → `rm_all` store 回滾、exit 1、不寫 db
  （不變量：db 有行 ⟺ 完整安裝）。
- `remove`：不在 db → `ctr: not installed` exit 1；否則
  store/bin 逐個 `unlink /bin/<f>`（報錯忽略）→ `rm_all` store
  → db 去行重寫。成功行：`pkg-removed <name>`。
- `list`：`PKGLS NAME VERSION` 表頭 + `PKGLS <name> <version>`
  逐行；無 db 視為空表（exit 0）。
- 包名規則沿用 `valid_name`（<24、無 `/`，順帶擋 registry 路徑穿越；
  layer 內路徑由 untar `mkdir_parents` 守）。

## 2. suite（確定性設計：裝→看→跑→刪）

第一包 `hello` = echo ELF 改名（`bin/hello`）+ `hello.txt`
（內容行 `pkg-hello-txt`）。autorun（logtest 段後）：

```
ctr install 10.0.2.2 8091 hello   → pkg-installed hello 1.0
ctr list                           → PKGLS hello 1.0
hello hello-from-pkg               → hello-from-pkg（sh resolve /bin/hello）
cat /pkg/hello/hello.txt           → pkg-hello-txt（store 落盤證明）
ctr remove hello                   → pkg-removed hello
```

- test.sh +5 項（run1）：上列五個 marker。
- registry（`tools/img_registry.py`）：加 `/pkg/hello/manifest`
  + `/pkg/hello/hello.tar` 路由，啟動時用 stdlib tarfile 現包
  （ECHO_ELF 讀法沿用 testimg）。test.sh 啟停不動。
- 手動：重裝（already installed）、刪不存在（not installed）、
  裝含 `bin/echo` 的包（shadows 拒絕）。
